# Pociťátko mockups

These screenshots illustrate a possible read-only historical layer for a
gentle, administrator-approved import of old `vymysli_vtipny_textik` rounds.
They are discussion material, not a claim that historical scraping or these
statistics are already live.

## Proposed historical features

- `history-overlay-concept.png` — past winners, the running club ranking, and
  a few aggregate records. All names and numbers are illustrative mock data.
- `avatar-stats-hover-concept.png` — a compact translucent hover/focus summary
  attached to an Okoun avatar. All figures are illustrative mock data.

## Current userscript

- `current-source-selection.png` — the existing visual source-image and round
  boundary confirmation step.
- `current-round-review.png` — the existing evidence-first vote review,
  suggested winner, reaction list, and manual exclusion controls.

Database and administrator controls are intentionally hidden in the current-UI
screenshots because this set is meant to explain the moderation workflow and
the proposed low-impact historical read path.
